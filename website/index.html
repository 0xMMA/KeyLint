Features

Text fixes that stay out of your way

⚡

Silent Fix

Select text in any app and press Ctrl+G. The corrected text replaces your selection — no window, no interruption, no copy-paste loop.

✍️

Pyramidize

Hold Ctrl and tap G twice to turn rough notes into a clear email, memo, wiki page or slide outline — main point first. Pick a style, refine it, then send it back.

🤖

Bring your own AI

An OpenAI or Anthropic API key, a local model through Ollama — or the Claude Code CLI you're already signed in to, with no key at all. How that works

🌍

Multilingual

Writes in English? Fixed in English. German? Fixed in German. KeyLint detects the language and corrects without translating.

🖥️

System Tray

Lives in your system tray. Single-click for the menu, double-click to open. Uses minimal resources.

🔒

Private

Your text goes from your PC straight to the provider you picked — no KeyLint server in between. No telemetry, no cloud sync, no clipboard history stored.

See it work

Rough notes in, a clear email out

Pyramidize puts the point first and the details after it. Press the shortcut twice on selected text, or paste it in, and edit the result before it goes anywhere.

AI providers

Use the AI you already have

OpenAI Anthropic API Claude Code CLI (installed) Ollama (local)

An API key

OpenAI or Anthropic: paste your key once. It is kept in your operating system's keyring and only ever sent to the provider it belongs to.

No key: the Claude Code CLI

Already signed in to Claude Code on this PC? Then you need no API key. KeyLint runs your installed claude command, unmodified, so usage counts against your own Claude plan. KeyLint never reads, stores or forwards your credentials and never asks you to log in: you sign in to Claude Code in your own terminal.

Local: Ollama

Run a model on your own machine with Ollama. Your text never leaves your PC.

Claude Code is Anthropic's product. KeyLint is an independent project and is not affiliated with or endorsed by Anthropic.
