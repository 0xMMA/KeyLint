why: Rule 4 plus rule 8. The author switches to English for the last clause on
  purpose; translating it into German flattens exactly what rule 8 calls "how
  multilingual minds naturally reach for the nearest word".
  "red" is the same phenomenon in miniature and is kept for the same reason. An
  earlier version of this reference translated it to "rot" and defended it as
  ordinary German developer speech — which it is, but this is the one sample
  whose thesis is that the author's word choice survives. A suite that argues
  against itself inside a single file measures nothing, so "rot" is forbidden
  here rather than modelled.
  The elision "ich hab" is left alone deliberately — chat-ton keeps the same
  elision, and demanding it be expanded here while accepting it there would make
  the suite disagree with itself about what correct means.
